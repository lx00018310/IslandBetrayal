# 荒岛分赃 (ForgeaX Game)

造化首届体素游戏创作大赛参赛作品。基于天工引擎（`@forgeax/engine 0.4.19`）原生 2.5D 正交体素管线与 Cordis 原生 Plugin 开发。

> **一句话玩法**：10 名角色在不断缩小的体素荒岛上生存，靠近他人可双方确认结盟攒宝，也能主动拉开距离引爆共享宝箱、哄抢散落战利品，或主动攻击其他队伍打爆宝箱，争做唯一幸存者。

## 核心玩法机制

1. **自由结盟与双方确认**：
   - 靠近距离 ≤ 2.4m 时弹出目标选择。
   - 一方发送邀请，另一方需在 5 秒有效期内接受才正式成立。
   - 双方结盟后生成发光连线束，并在两名队友正中位置生成共享宝箱。
   - 合作期间击杀怪物，获得的宝物自动存入共享宝箱；结盟提供 +3 基础攻击力加成，宝箱财富提供额外攻击增益。

2. **忽略 60 秒屏蔽**：
   - 玩家或 AI 可对当前目标选择“忽略 60 秒”。
   - 屏蔽期内双方无法互邀或成队，到期后自动恢复；重试不延长屏蔽。不影响与场上其他角色结盟。

3. **连线预警与超距断线爆箱**：
   - 队友之间需保持距离。距离达到 4.0m 时发光连线**变红预警**，HUD 出现警报提示。
   - 距离严格超过 5.0m 时连线断裂，队伍立即解散。
   - 解散时共享宝箱在当时**两人的精确中点**引爆，全部宝物飞散落地，供全场角色自由哄抢。

4. **外部掠夺破箱**：
   - 攻击拥有共享宝箱的敌方角色会优先损耗其宝箱耐久。
   - 宝箱被外人打爆后，宝物四散供所有人争抢；**原队友依然保持结盟连线关系**，直至后续超距断线或被淘汰。

5. **荒岛缩圈与胜负结算**：
   - 随着时间推移，外围地块逐步崩塌下沉坠入虚空。
   - 掉出地图边缘或生命值归零即被淘汰。
   - 决出最后一名存活角色为冠军，展示获得宝物、打爆宝箱次数、断线解散次数与淘汰人数。

## 技术架构

- **纯逻辑模拟** (`assets/island/simulation.ts`)：无任何 DOM、Canvas 或引擎全局状态依赖，在独立的对局时钟中单向推进，完整受 Vitest 单元测试覆盖。
- **原生艺术与场景包** (`assets/island/art.pack.ts`)：受管的体素草地、薄层地面、10 角色服装/头发/面容部件、怪物、宝箱、发光连线束（正常与预警红）、72 个战利品实体池与脚底接触影。
- **呈现控制层** (`assets/island/presentation.ts`)：原生正交相机跟随（55° 俯角近景跟随主角）、脚底接触影、行走呼吸微动画、受击红闪、地块崩塌与重置。
- **原生插件与只读投影** (`assets/island/island.pack.ts`)：原生 Cordis 插件，驱动 ECS Update 循环；发布 `island.match` 只读验收投影，并通过端口跨领域向前端同步轻量级 HUD 状态。
- **原生 HUD** (`assets/guide.ui.html`, `assets/guide.ui.css`, `assets/ui/guide-controller.ts`)：符合天工引擎 UiAuthoringProfile 的原生界面，适配桌面与移动端各分辨率。
