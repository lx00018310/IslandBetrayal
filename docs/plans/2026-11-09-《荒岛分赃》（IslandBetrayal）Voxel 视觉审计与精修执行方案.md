## 第一部分：首轮代码变更深度 Review（问题清单）

### 1. \[P0 严重遗漏\] `presentation.ts` 动态表现严重偷工减料（仅完成 $25\%$）

* **现状**：本地 AI 仅在 `presentation.ts` 中添加了基础的移动跳跃缩放区间（`0.85 ~ 1.25`），改动量极小。

* **缺失项**：

  1. **无体素物理粒子池（`VoxelVfxPool`）**：掩体被摧毁、Boss 受击、角色跳跃落地、金币飞溅时，没有任何 $1 \times 1 \times 1$ 小体素方块的抛物线迸裂弹跳效果。

### 2. \[P0 视觉缺陷\] 体素三面明暗与折角 AO 未在渲染材质中生效，同色方块“糊成一团”

* **现状**：`voxel-builder.ts` 虽然生成了合并网格，但在 `@forgeax/engine` 的标准材质管线中，如果同一个颜色部件的所有面共享同一个纯色材质且无方向性色阶区分，顶面、正面与侧面的明度差极小。

## 第三部分：三大核心优化 / 改造 / 重构建议

为了让画面从“粗糙方块demo”跃升为“精致潮玩体素作品”，必须实施以下三项关键重构：

### 建议一：【渲染管线重构】引入「法线朝向 + AO 烘焙色板（Baked Shading Palette）」解决糊块问题

不要依赖引擎默认的漫反射去区分体素块立面！在 `voxel-builder.ts` 与 `art.pack.ts` 中：

1. 将每个颜色色号自动派生出 **4 档方向光影材质/UV 色格**：

   * **顶面（$+Y$）**：固有色提亮 $+8\%$（暖阳光受光面）；

   * **左前主面（$+Z / -X$）**：固有色明度 $85\%$；

   * **右后暗面（$+X / -Z$）**：固有色明度 $62\%$ 并向冷紫蓝偏移；

   * **底面与内折角（$-Y$ 或 Cavity AO $\ge 2$）**：固有色明度 $45\%$（厚重接触阴影）。

2. 在 `VoxelBuilder.buildGreedyMesh()` 合并同色面时，按法线朝向与折角遮蔽度分配对应的色阶材质或 UV 坐标。这样每一个体素台阶、木箱凹槽、小狗鼻头都会呈现出**刀刻般清晰、极富波普艺术感的立体棱角**！

### 建议二：【环境沙盘重构】打造「立体棋盘格海岛 + 脉冲白浪花方块 + 方格翻红预警」

将单调的圆形场地彻底重构为微缩景观模型（Diorama）：

1. **棋盘格草坪表层**：使用 `#78E060` 与 `#68D050` 两种微差翠绿体素块按 $(x + z) \bmod 2$ 交替铺设海岛顶面，天然形成《天天过马路》的跳格视觉引导。

2. **阶梯沙滩与动态浪花环**：草坪外圈下沉 1 格为暖金沙滩（`#F7D070`），最外圈海面环绕 24 簇纯白浪花体素块（`#FFFFFF`），在 `presentation.ts` 中随 $\sin(t + \text{index})$ 做离散像素级上下浮动与缩放。

3. **体素方格预警**：Boss 释放技能时，预警区域不再是平滑贴片，而是由一组 $1 \times 1 \times 0.25$ 的高亮猩红体素块从地面向上脉冲弹起。

### 建议三：【动态反馈与 UI 重构】实装「128 容量体素碎块池 + 双色温背叛光影 + 4px 硬投影波普 HUD」

1. **Voxel Shatter Pool**：在 `presentation.ts` 中预创建 64～128 个通用小方块粒子，任何掩体受击/破碎、Boss 掉血、玩家起跳落地或拾取金币时，立刻从池中激活 $6 \sim 16$ 颗对应配色的体素小方块，执行带重力加速度 $g = -18\text{ m/s}^2$ 与地面反弹系数 $e = 0.45$ 的物理弹跳。

2. **Dual-Mood Lighting**：实时监听 `simulation.ts` 中的背叛/悬赏状态，触发时将环境色温切换为霓虹暮色，并在叛徒头顶生成旋转的发光红色骷髅体素块。

3. **Pop Blocky HUD**：重写 `guide.ui.css`，所有面板与按钮采用粗黑描边（`2px solid #1E293B`）+ 底部实体积木厚度阴影（`box-shadow: 0 4px 0 #0F172A`）。

### 5.3 本轮修复的真实缺陷

1. **预警填充偏移到画面外**：`voxelTelegraphGrid()` 初版把小数坐标传给要求整数格的 `voxel()`，导致 AABB 为 `-1,-64,-64 … 2,33,65`。改为整数格 + `unit` 缩放后修正，并补了「包围盒以圆心对称 + 圆心被三角形覆盖」的断言。
2. **落地挤压方向反了**：`hopPose()` 初版让 XZ 也一起缩小，视觉上读成「整体缩小」而不是「落地压扁」。单测先失败并抓到该问题，改为 Y 压扁 + XZ 膨胀。
3. **双色温把海面染成粉色墙**：初版暮色参数 `[1.0, 0.62, 0.72]` + 强度 2.35，配合 60×60 受光海面，整片背景变粉、压掉预警与身份辨识。按方案「若明暗变化遮蔽预警则删除该效果」的红线处理：主光改 `[1.0, 0.86, 0.90]`、最大混合度限 `0.7`，并把海面改为 **unlit 固定深海军蓝**。
4. **接地阴影变成硬边深色方板**：把平面/圆柱阴影换成薄方块后，单层 alpha 方板在水平视角下成了实心方框。改为「外圈淡 + 内圈深」两层方块拼的柔和阴影，材质 `depthWriteEnabled: false`。
5. **非方块辅助几何**：脚底环 / 方向箭头 / 预警环原为 torus / cone / cylinder，与方案「全场景 100% 立方体」冲突，改为 `squareFrame()` / `arrowBlocks()` 方块拼片，并新增断言「所有法线必须轴对齐」。
6. **playthrough 脚本预算被耗尽**：预警轮询改为只在团战阶段执行，并在轮询后重读状态（`const s` → `let s`），否则后续截图与断言用过期状态。
