## 0. 总体裁决：砍掉冗余、锁死“三大玩法支柱 + 三大视觉方向”

若 `docs/plans/` 下旧文档与本 Plan 冲突，**一律以本 Plan 为最高权威准绳**。

### 0.1 明确砍掉/废弃的设计（禁止实现，若已有半成品请回退或归并）
1. **不要“拔河重心爆箱”**：不增加按住 `Space` 减速拽箱子或按贡献偏移落点的子机制，保持纯粹、直观的**断线中点爆箱**。
2. **废弃“Boss 战强制全员和平同阵营 & 暂停主时钟”**：$120\text{s}$ 与 $240\text{s}$ 刷新 Boss 时，**不暂停主时钟、不关停 PvP、不冻结断线爆箱**。Boss 是引爆黑吃黑的催化剂，不是和平副本。
3. **废弃“无限模式失败 20 层全属性减益负担 (`lossBurden`)”**：不惩罚输家下一局的基础属性，防止单机无限模式下玩家因负反馈直接删档。
4. **废弃“移除一切属性上限与超 $100\%$ 多层暴击结算”**：保持 `stats.ts` 清晰可控的数值边界，把跨局变化聚焦在**博弈杠杆秘策**。
5. **禁止靠“盲目切碎体素网格”来修画质**：解决看不清的问题必须靠**明度分层、剪影体量阶梯、脚底锚定底盘**，严禁无脑翻倍体素面数拖垮微信小游戏帧率。

### 0.2 核心架构总览
* **玩法三大支柱**：
  1. **【空间化的囚徒困境】**：双人连线、共享宝箱先承伤、超距（基础 $5.0\text{m}$）**中点爆箱** + `Space` 单键结盟/背叛。
  2. **【掩体缩圈下的 Boss 悬赏黑吃黑】**：每分钟安全区半径缩小 $15\%$ + 中央 $2\sim 3$ 处实体岩石掩体（挡移动与直线视线）+ $120\text{s}/240\text{s}$ 悬赏 Boss（攻击注资共享宝箱、高价值仇恨预警 AOE、残血引爆背刺）。
  3. **【10 人暗标“世界秘策”与 AI 记仇生态】**：持久化存档（`EndlessSaveV1`）+ 修改博弈杠杆的秘策池 + **AI 跨局记仇记忆**（暗标针对性克制、局内拒盟或假结盟反杀）。
* **视觉三大重构方向**：
  1. **【图层明度剥离与背景降噪】**：压低地面对比度与噪点，用明度（Luminance）和饱和度（Saturation）将“地形、掩体、角色/怪、弹药”拆成 4 个互不粘连的视觉层。
  2. **【俯视角夸张剪影与体量阶梯】**：砍掉 1 格碎体素，建立“矮扁小怪 $<$ 大头角色 $<$ 厚重梯形掩体 $<$ 巨型异形 Boss”的四级体量阶梯，并将弹药反写实放大 $1.6\sim 2.0$ 倍。
  3. **【脚底功能底盘、Fake AO 与纵向受光梯度】**：全员绑定高辨识度脚底圆环/硬阴影底盘，掩体底部加暗边（Fake AO），立体模型施加“上亮下暗”纵向顶点色梯度。

## 第一部分：三大核心玩法机制规范

### 1. 玩法支柱一：双人连线与共享宝箱中点爆箱（稳固与提纯）

1. **纯粹中点爆箱**：两名存活角色结盟期间共享同一个队伍宝箱（位于两人连线中点，优先承受敌方攻击并保护队友免受彼此伤害）。当两人距离超过当前有效断线阈值 $D_{\text{break}}$（基础值 $5.0\text{m}$），或任一方主动按 `Space` 触发背叛/解盟时，共享宝箱在**两人连线几何中点**爆开，散落高价值战利品供全场哄抢。
2. **外部破箱不散队**：敌对玩家、AI、怪物或 Boss 打破共享宝箱时，仅爆出部分战利品，**不解除双方结盟状态**。
3. **攻击目标优先级修复（Review R03）**：
   * 在 `stepSimulation()` 与 `resolveHostileHit()` 中，角色自动攻击改为**威胁与价值评分锁定**：距离内正在哄抢战利品的残血敌人 $>$ 距离内敌队高价值共享宝箱 $>$ 贴脸精英怪/Boss $>$ 普通怪。
   * 保持同队队友与本队共享宝箱绝对免伤。

### 2. 玩法支柱二：掩体缩圈下的“Boss 悬赏黑吃黑”

#### 2.1 分段缩圈与终局空间挤压（Review R14）
废除旧版按进度连续线性缩圈，改为**主时钟分段缩圈**（主时钟永不因 Boss 暂停）：

| 主对局时间 | 安全半径相对初始比例 $R_{\text{safe}}$ | 阶段说明与博弈焦点 |
| :--- | :---: | :--- |
| $0\text{s} \sim 59\text{s}$ | $100.00\%$ | 外围发育、寻找盟友、建立初始共享宝箱 |
| $60\text{s}$ | $85.00\%$ ($0.85^1$) | 第一圈收缩：边缘坍塌，队伍被迫向中圈靠拢 |
| $120\text{s}$ | $72.25\%$ ($0.85^2$) | **第二圈收缩 + 第一场悬赏 Boss 降临中央** |
| $180\text{s}$ | $61.41\%$ ($0.85^3$) | 第三圈收缩：中圈高密度遭遇与破箱 |
| $240\text{s}$ | $52.20\%$ ($0.85^4$) | **第四圈收缩 + 第二场悬赏 Boss 降临 + 强制终局解盟倒计时** |
| $260\text{s} / 280\text{s} / 300\text{s}$ | $44.00\% \rightarrow 36.00\% \rightarrow 30.00\%$ | 终局中心竞技场极速收束，围绕中央掩体决出唯一胜者 |

* **平滑坍塌不瞬杀**：每次缩圈触发前 $5\text{s}$ 在 HUD 与地面显示边界预警光带；触发后在 $5\text{s}$ 内平滑推进安全半径。站在崩塌边缘的角色与普通怪物受地形约束或向内推挤，不发生同帧瞬杀，普通怪物不得悬空走入水体（Review R08）。
* **底层防拖局加速（隐性节奏器，Review R13）**：单局内每淘汰 $1$ 名参赛角色（`eliminate()` 唯一入口去重，仅计 $10$ 人阵容，不计怪物/Boss），场上仍存活角色的伤害乘以独立乘区：
  $$M_{\text{survival}} = b^{N_{\text{eliminated}}}$$
  （默认底数 $b = 1.20$，可被世界秘策微调）。仅在最终伤害出口结算一次，换局清零。

#### 2.2 中央实体体素岩石掩体（走位与视线博弈）
1. **布置规则**：在地图中心区域（在 $30\%$ 极小安全区内仍至少保留 $2$ 处）布置 $2\sim 3$ **处固定体素岩石掩体**，每处掩体周围留有可绕行通道，不形成死胡同。
2. **双重物理与战斗判定**：
   * **移动阻挡与滑墙**：玩家、AI、普通怪移动时碰撞岩石半径则沿切线滑行（分轴测试 $X/Y$ 位移），不可穿模。
   * **直线视线遮挡（Line-of-Sight, LoS）**：普攻、穿透箭矢的线段若与岩石掩体碰撞圆相交，则被岩石拦截；飞刀无法隔石命中；炸弹爆炸中心与目标连线被岩石遮挡时，目标承受伤害减免 $70\%$（乘以 $0.30$）。
3. **极简 AI 绕障**：当 AI 与目标连线被岩石阻挡或移动受阻时，自动选取岩石左右切点作为临时路点绕行，严禁在岩石前原地卡死。

#### 2.3 $120\text{s}$ 与 $240\text{s}$ 悬赏 Boss 黑吃黑机制
1. **全自由 PvPvE**：主时钟到达 $120.0\text{s}$ 与 $240.0\text{s}$ 时，在中央安全区刷新悬赏 Boss（移除旧 $180\text{s}$ 触发）。**不暂停主时钟、不把所有人改成同一阵营、不关闭 PvP 与断线爆箱**。
2. **悬赏注资与仇恨嫁祸**：
   * **攻击即分赃**：任何角色对 Boss 造成有效伤害，按伤害比例实时向该角色（或所属双人队伍的共享宝箱）注入额外战利品/积分；击杀 Boss 掉落高价值公开宝箱与必掉升级宝物。
   * **高价值仇恨与预警 AOE**：Boss 优先锁定场内**当前战利品最高或最近对其输出最高**的角色，周期性释放带地面红色预警圈（$1.5\text{s}$ 前摇）的大范围冲击波。冲击波可被**中央岩石掩体遮挡减免 $70\%$**。
   * **借刀杀人**：玩家可通过走位将 Boss 预警圈引向敌队，或在双人连线状态下绕过岩石掩体，把盟友卡在 Boss 攻击范围内借刀杀人、独吞爆箱。
3. **残血猜疑链与终局解盟**：
   * 当 Boss 血量低于 $20\%$ 时，贪财鬼（Greedy）与掠夺者（Raider）AI 显著提高背叛倾向：若本队共享宝箱已累积丰厚战利品或旁边有残血竞争者，主动断开连线或转火偷袭残血玩家。
   * 第二场 Boss（$240\text{s}$）被击杀或存活满 $35\text{s}$（至迟 $275\text{s}$），立即触发全场最终阶段强制解盟，进入最后单人决战。

#### 3.2 AI 跨局记仇记忆（Grudge System，重构 R06）
在每名参赛者的持久化档案 `EndlessProfile` 中，新增仇恨记忆字段：

```ts
export interface GrudgeRecord {
  lastBetrayedById: number | null; // 上一局背叛拉爆自己箱子的仇人 ID
  lastKilledById: number | null;   // 上一局直接击杀自己的仇人 ID
  grudgeScoreByActor: Record<number, number>; // 对各角色的累计仇恨值 0..100
}
```

1. **记仇触发**：主动按 `Space` 背叛或恶意拉断连线爆箱，受害者对背叛者仇恨 $+50$（记录 `lastBetrayedById`）；直接击杀或淘汰对方，受害者对凶手仇恨 $+30$（记录 `lastKilledById`）；每局结束未发生新冲突则自然衰减 $15$ 点。
2. **暗标阶段克制投票**：在 `aiDecideNextRound()` 中，对本局胜者或玩家持有高仇恨（$\ge 40$）的 AI，有 $70\%$ 概率针对性投出克制仇人当前携带宝物（`carryRelic`）的秘策（如仇人带飞刀则投 `ranged_snipe`，带箭矢则投 `close_combat`）。下一局开场 HUD 点名播报 AI 的记仇投票。
3. **局内结盟报复**：仇恨值 $\ge 50$ 的老实人 AI 直接拒绝玩家的 `Space` 结盟；贪财鬼/掠夺者 AI 会假意结盟，一旦共享宝箱积累战利品或靠近 Boss 预警圈立即背叛反杀。

#### 3.3 唯一词条宝物与持久化无限存档（R07 / R10 / R11）
* 3 种武器（飞刀、箭矢、炸弹）作为跨局唯一携带宝物 `carryRelic`，每件附带 $1$ 条固定词条（飞刀数量 $+1$、箭矢穿透 $+1$、炸弹半径 $+15\%$）。

## 第二部分：三大视觉辨识度重构规范（彻底解决“糊成一团”）

针对当前“角色、怪物、障碍物、地形、Boss、弹药全都像一团马赛克，互相分辨不出”的问题，必须在 `pixel-art-data.ts`、`art.pack.ts`、`materials.pack.ts` 和 `presentation.ts` 中完整落地以下**三个方向的改造**：

### 4. 视觉方向一：图层明度剥离与“背景降噪”（零建模负担，最高优先级）

**设计原理**：人眼在俯视角混战中首先靠**明度对比（Luminance）**和**色相纯度（Saturation）**分层。必须把背景地板压暗、降噪，把前景交互单位提亮、提纯。

#### 4.1 四大视觉图层色板规范（Palette Discipline）

| 视觉图层 | 包含对象 | 目标明度区间 $L$ | 目标饱和度区间 $S$ | 具体改造要求（修改 `pixel-art-data.ts` & `art.pack.ts`） |
| :--- | :--- | :---: | :---: | :--- |
| **L0 底板层** | 草地、沙地、岩石地面、水体 | $0.25 \sim 0.42$ | $0.12 \sim 0.28$ | **强制背景降噪**：砍掉地面相邻方格的深浅剧烈跳动，相邻地块明度差 $\Delta L \le 0.05$；移除地面细碎杂色点，让海岛地面成为安静的暗调画布。 |
| **L1 掩体层** | 中央 $2\sim 3$ 处实体岩石掩体 | 侧面 $0.22 \sim 0.32$<br>顶面 $0.55 \sim 0.65$ | $0.08 \sim 0.18$ | **冷色大块面化**：严禁使用与泥土/小怪雷同的灰褐色。统一改为**深冷青灰岩色（如 `#3A4652`）**，顶部受光平面强制平涂**高亮冷灰（如 `#8FA1B3`）**，形成鲜明硬边台面。 |
| **L2 单位层** | 玩家、9 名 AI、普通怪、悬赏 Boss、共享宝箱 | $0.65 \sim 0.95$（角色/焦点） | $0.75 \sim 1.00$ | **高对比色相锁死**：见下方 4.2 角色与怪物专属配色规范。 |
| **L3 弹药与预警层** | 飞刀、箭矢、炸弹、连线、Boss 预警圈 | $0.85 \sim 1.00$ | $0.85 \sim 1.00$ | **最高明度自发光感**：所有弹药核心采用纯白/高亮黄（`#FFFFFF` / `#FFF066`），外框配高纯度霓虹色（青 `#00F5D4`、亮橙 `#FF6B00`、炽红 `#FF1E42`）。 |

#### 4.2 角色、普通怪、Boss 与宝箱的色彩隔离
1. **玩家与 AI（Tibo 风格高明度主体）**：
   * 身体/面部主色统一采用高明度暖白/浅奶油色（如 `#F7F3E8`），确保在暗色地面上 $100\%$ 跳出。
   * 玩家固定穿戴**高纯度翠绿/亮金**标志物；9 名 AI 按性格划分为 3 组高饱和度识别色（老实人：天蓝 `#38BDF8`；贪财鬼：亮琥珀金 `#FACC15`；掠夺者：品红/亮紫 `#E879F9`）。
2. **普通怪物（暗体亮核）**：
   * 躯干统一使用低明度深紫黑或深墨绿（`#1E1B2E` / `#162A24`），绝不与浅色角色混淆；
   * 必须在怪物头顶/眼部/背部中心点缀 $2\sim 4$ 格**高纯度亮橘红/荧光绿视觉焦点**（`#FF4D00` / `#70E000`），让怪潮既有威胁感又清晰可数。
3. **悬赏 Boss（黑金炽红霸权）**：
   * 主体采用曜石黑（`#141218`）配亮金装甲块（`#FFD166`）与炽红核心（`#FF1E42`），全身在 `presentation.ts` 中附加周期性明度呼吸脉冲，一眼区别于任何普通小怪。
4. **共享宝箱（高光亮金）**：
   * 箱体采用高饱和度皇室金（`#FFB703`）配亮白锁扣，禁止使用暗棕色木箱（暗棕色在泥地上完全隐形）。

### 5. 视觉方向二：俯视角“夸张剪影与体量阶梯”（改长宽比，砍掉碎体素）

**设计原理**：在斜俯视镜头下，玩家看的是**“头肩顶视图”**和**“占地长宽比”**。所有 $1\times 1$ 格的琐碎装饰体素在缩小的屏幕里都是噪点，必须合并为大块面几何结构，并拉开四级尺寸差距。

#### 5.1 强制四级体量阶梯（Scale & Aspect-Ratio Hierarchy）

| 等级 | 对象类别 | 相对角色高度比 | 占地长宽比（宽 $\times$ 深 $\times$ 高） | 俯视角剪影特征（修改 `art.pack.ts` 网格生成） |
| :--- | :--- | :---: | :---: | :--- |
| **Tier 1** | **普通怪物** | $0.55\times \sim 0.65\times$ | $1.25 : 1.25 : 0.60$ | **矮扁匍匐剪影**：压低高度、加宽底座（类似毒蜘蛛/史莱姆/匍匐兽），视觉重心紧贴地面，绝不像直立小人。 |
| **Tier 2** | **玩家与 AI** | $1.00\times$（基准） | $1.00 : 1.00 : 1.35$ | **二头身大头剪影**：放大头部体素块至全身高度的 $45\%\sim 50\%$，砍掉细碎四肢噪点，从斜上方看具有饱满圆润的亮色头冠轮廓。 |
| **Tier 3** | **中央岩石掩体** | $1.40\times \sim 1.60\times$ | $2.60 : 2.60 : 1.50$ | **厚重梯形台柱**：底座宽大、顶部收窄的阶梯状巨石，占地面积至少是角色的 $6$ 倍以上，绝不可能被误认为单位。 |
| **Tier 4** | **悬赏 Boss** | $2.50\times \sim 3.00\times$ | $2.40 : 2.20 : 2.80$ | **巨型异形剪影**：不仅体积巨大，且顶部必须向外伸出**夸张的横向双角或宽厚肩刺**，形成极具侵略性的外轮廓。 |

#### 5.2 弹药与投射物“反写实放大”与几何提纯
* **体积统一放大 $1.6\sim 2.0\times$**，砍掉暗色木杆和细小箭羽：
  1. **环绕飞刀（Spinning Knife）**：尺寸放大 $1.8\times$，造型改为**宽刃月牙光片**（亮白刀背 + 青色刀锋），围绕角色旋转时形成清晰的切线光弧。
  2. **穿透箭矢（Piercing Arrow）**：长度与宽度放大 $1.7\times$，造型改为**流线型亮黄色棱锥光矢**，尾部拖带 $1\sim 2$ 节半透明高亮残影块。
  3. **高爆手雷/炸弹（Bomb）**：球体半径放大 $1.8\times$，采用黑底 + 高亮红黄交替闪烁核心，并在落地预计爆炸处提前渲染**高对比度橙红边界圆环**。

### 6. 视觉方向三：脚底“功能性锚点底盘”、Fake AO 与纵向受光梯度

**设计原理**：借鉴《荒野乱斗》等成熟俯视角游戏的工业级方案，在单位与地面之间插入一层**高可读性的几何底盘（Ground Anchor）**，同时给体素赋予纵向明暗梯度，彻底消除“立体方块与地面方格糊成一片”的视觉粘连。

#### 6.1 全员脚底功能底盘（Ground Anchor Rings，在 `art.pack.ts` & `presentation.ts` 实现）
所有活动单位脚底貼地（高度 $y \approx 0.03\text{m}$）绑定一层扁平几何底盘：
1. **玩家自身（Actor 0）**：
   * 脚底常驻 **高亮翠绿外环（`#10B981`）+ 亮白内圈 + 前方朝向小三角箭头**。无论场面多乱，玩家能在 $0.1\text{s}$ 内定位自己与移动朝向。
2. **当前结盟队友（Teammate）**：
   * 脚底常驻 **高亮天蓝圆环（`#0EA5E9`）**；两人与中点共享宝箱之间的连线加粗为高亮能量光束（距离接近 $D_{\text{break}}$ 的 $80\%$ 时，连线由蓝转急促红黄闪烁预警）。
3. **非队友 AI 角色（Rival AI）**：
   * 脚底常驻 **暗琥珀/暖红细警戒环**；若该 AI 对玩家拥有跨局高仇恨（`grudge >= 50`），脚底警戒环升级为**刺眼紫红色脉冲环**，直观提示“此人记仇高危”。
4. **普通怪物（Monsters）**：
   * 脚底绑定 **深黑色半透明圆盘硬阴影（Fake Drop Shadow，明度 $L \le 0.08$）**，不发彩光（避免光污染），专门负责把小怪轮廓从地面方格上干净地“垫”起来。

#### 6.2 中央岩石掩体底部暗边（Fake Ambient Occlusion）
* 在每处中央岩石掩体的底部接地处，外扩 $0.25\text{m}$ 生成一圈**深暗色接地底座（`#12161A`）**。这圈暗边能瞬间把掩体“钉”死在地面上，消除体素块悬浮或与地面融为一体的错觉。

#### 6.3 体素纵向受光梯度（Top-Down Vertical Gradient）
* 在 `art.pack.ts` / `uv-primitives.pack.ts` 生成角色、怪物、掩体、Boss 的体素网格颜色时，按每个体素块在该实体内的归一化高度 $h_{\text{norm}} \in [0, 1]$ 施加纵向明度乘区：
  $$C_{\text{final}} = C_{\text{base}} \times \left(0.72 + 0.46 \times h_{\text{norm}}\right)$$
  * **底部 $30\%$ 体素**：自动压暗约 $20\%\sim 28\%$，与脚底阴影自然衔接；
  * **顶部 $30\%$ 体素（头顶、肩部、岩石顶面）**：自动提亮约 $15\%\sim 18\%$，在俯视角下形成清晰的受光顶面与立体层次。
