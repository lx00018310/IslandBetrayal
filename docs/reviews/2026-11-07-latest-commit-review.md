## 参数与兼容性说明

- 终局前参赛角色互伤为最终命中伤害的 20%（至少 1）；敌队宝箱、Boss 的伤害保持全额；终局角色互伤全额。Boss 出现不改变这套规则。
- 主动 Space 背叛和超距解盟释放全部箱内财物；外部破箱公开散落一半，另一半平分归还两人，队伍保持。掉落物保留小数 value，拾取按实际 value 计账，避免新收入倍率造成财富复制或丢失。
- 同类秘策乘法累积后限幅：断线距离 3–8m、共享收入最多 3 倍、结盟移速最多 1.3 倍、全局额外移速最多 1.4 倍、悬赏伤害最多 3 倍、散落最多 2 倍、飞刀范围最多 1.8 倍、箭射程至少 0.5 倍；死亡底数为 1.20 或 1.25。缩圈额外修正受限，最终半径至少初始的 28%，并保留两处中央掩体。
- 最终属性边界：HP 最多 300；基础伤害乘数最多 4；移速 0.6–1.8 倍；攻速 0.4–2.5 倍；暴击 0–60%。独立死亡和武器秘策乘区另算。旧属性规则只用于读取已有 v1 历史，新投票只产生七种具名秘策。
- 唯一携带宝物的固定词条改为：飞刀数量 +1、箭穿透 +1、炸弹半径 +15%；敌人难度为 `1 + 0.12 × (局号 - 1)`。
- 用户建议中的降噪、局部发光核心、弹药高亮、顶点梯度、AO 已采用；示例中的 emissivePulseSpeed、临时内联材质/伪 Entity API 不直接复制。本次沿用原生资产链与材质，没有加入 Toon Shader 或新渲染框架。
