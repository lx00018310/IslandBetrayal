## 二、AI 工具创作范围与占比声明

| 项目 | 说明 |
| :--- | :--- |
| **所用 AI 工具** | WorkBuddy Agent / 腾讯混元及深度学习辅助编程助手 |
| **AI 创作范围** | 1. 核心游戏玩法模拟（结盟、断线中点爆箱、怪潮波次、肉鸽升级三选一）代码编写与重构；<br>2. 3D 体素几何参数化生成算法与调色代码；<br>3. 原生正交跟随摄像机与多端响应式 HUD 界面排版；<br>4. 自动化测试脚本与端到端试玩验收断言编写。 |
| **人工设计与主导范围** | 1. 核心创意与博弈原则（合作攒宝、断线开抢、外部掠夺）；<br>2. 赛事 15 分钟连续挑战机制设定与数值边界把控；<br>3. 审查、修复与全流程验收把关。 |
| **综合 AI 辅助占比** | 约 **65%**（代码实现与算法由 AI 辅助生成，架构、创意与评审由参赛者深度主导与决策）。 |
