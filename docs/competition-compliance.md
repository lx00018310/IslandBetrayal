## 二、15 分钟连续挑战实现与核算依据

1. **单局竞技与全局会话分离**：
   - 单局保留原汁原味的 300 秒荒岛缩圈混战节奏，每局 XP、队伍连线、宝箱财物完整清空，避免数值无度通胀破坏平衡。
   - 会话维护 `session.challengeElapsed` 与 `session.roundsCompleted`，记录本次挑战的实际有效游玩时间。
   - 新增「无限挑战模式」（Endless Mode），10 名参赛角色拥有各自独立的成长历史，局末可秘密选择影响下一局全场的属性规则（乘法累乘）并携带一件武器宝物（保留等级），形成长线连续博弈。
2. **防作弊与纯净计时**：
   - **升级三选一全局暂停时不累计时长**（避免挂机选卡刷时长）；
   - **结算弹窗展示期间不累计时长**；
   - **4 倍演示加速期间不累计挑战时长**；
   - **玩家阵亡后不计入有效操作时长**；
   - 本局结算后可点击【进入下局秘策选择】继续；达到 900 秒需要多少局取决于玩家每局实际存活时长，不能以局数代替时长证据。
3. **极简操作保障与跨端覆盖**：
   - PC 端采用 WASD/方向键 + Space 组队/确认的唯一战斗键位，降低操作门槛；
   - 移动端仅保留虚拟摇杆 + 右侧【组队】唯一常驻按钮，适配不同设备评委试玩。
4. **时长结构的强化（2026-11-06 V2）**：
   - 单局内新增 **120s 与 240s 两场全员 Boss 团战**（所有存活角色强制参战），把单局节奏拉长为「组队 → 割草 → 团战 → 缩圈 → 二团战 → 掩体决战 → 结算」的完整曲线；
   - 团战期间主对局时钟冻结，但**真实参与时间照常计入赛事有效体验时长**（仍受「玩家存活 + 1× 速度 + 未暂停 + 未结算」限制，不虚增）；
   - 无限模式新增**浏览器本地持久存档**，刷新/关闭后可恢复第 N 局、全部规则、携带宝物与失利负担，方便评委分多次连续体验累计 ≥900 秒。

> **如实说明**：本版已通过自动化端到端脚本验证「两场团战、缩圈档位、死亡增伤、存档恢复/清空、升级队列」等机制正确性（57 步全绿）；但**真人实际连续游玩 ≥900 秒尚未由人工计时完成**，赛事时长声明仍需真人实测补证，不以自动推进代替人工体验记录。
